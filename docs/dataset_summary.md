# Dataset summary
The canonical fixtures contain 50 resume rows and 20 job-description rows. Resumes use fields `resume_id,candidate_label,email,phone,skills,education,experience_years,job_category,resume_text,cleaned_text`. JDs use `jd_id,job_title,required_skills,preferred_skills,experience_required,education_required,job_category,job_description,cleaned_text`. Values are synthetic.
